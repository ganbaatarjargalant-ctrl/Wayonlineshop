# Сургалтын сайт — Frontend зураг төсөл

Огноо: 2026-10-12
Төлөв: Ноорог (батлагдаагүй)

## 1. Зорилго, яагаад

Танхимын болон онлайн сургалтуудын мэдээллийг нэг сайтад харуулах.

- **Танхимын сургалт** — хэрэглэгч дэлгэрэнгүй мэдээлэл, үнэ, холбоо барих утасны дугаарыг хараад утсаар холбогдож бүртгүүлнэ. Сайт дээр төлбөр, бүртгэл байхгүй.
- **Онлайн сургалт** — хэрэглэгч сайтад бүртгүүлж (username + нууц үг), QPay-ээр төлбөрөө төлөөд, видео хичээлүүдээ сайт дээрээ үзнэ.

Өнөөдрийн ажил: **зөвхөн frontend**. Backend дараа нь хийгдэнэ. Тиймээс бүх өгөгдөл mock байна, гэхдээ backend-тэй холбоход хялбар байхаар бүтэцлэнэ.

## 2. Зорилтууд

- Хэрэглэгчийн харах бүх хуудас ажиллаж, хооронд нь шилжиж болдог байх.
- Танхим / онлайн сургалтын ялгаатай урсгал тодорхой харагдах.
- Онлайн сургалтын бүтэн урсгалыг mock-оор туршиж болох: бүртгүүлэх → нэвтрэх → худалдаж авах (QPay QR) → хичээл үзэх.
- Утас болон компьютер дээр зөв харагдах.

## 3. Хийхгүй зүйлс (Non-goals)

- Админ хуудас (сургалт нэмэх/засах) — хэрэггүй.
- Backend, өгөгдлийн сан, жинхэнэ QPay холболт, жинхэнэ нэвтрэлт.
- Танхимын сургалтад онлайн бүртгэл / төлбөр.
- Видеоноос өөр хичээлийн материал (PDF, тест гэх мэт).

## 4. Анти-зорилтууд (техникийн хувьд ажилласан ч бүтэлгүйтэл гэж үзэх)

- Mock өгөгдөл компонентууд дотор тархаж, backend холбоход бүх хуудсыг дахин бичих шаардлагатай болох.
- Худалдаж аваагүй хэрэглэгч онлайн хичээлийн видеог үзэж чадах (mock түвшинд ч гэсэн хамгаалалтын логик байх ёстой).
- Танхимын сургалт дээр "Худалдаж авах" товч гарч төөрөгдүүлэх.

## 5. Хэрэглэгчийн шийдсэн зүйлс

- Технологи: **React**.
- Нүүр хуудасны загвар: **A хувилбар** — цэвэрхэн, hero + хайлт, "Бүгд / Танхим / Онлайн" шүүлтүүр, сургалтын картын grid.
- Төлбөр: **QPay** (одоохондоо mock QR дэлгэц).
- Нэвтрэх: **username + нууц үг**.
- Онлайн сургалт = **видео хичээлүүд**.
- Холбоо барих мэдээлэл: утас **88777988**, имэйл **mr.tuumii@gmail.com**.
- Админ хэрэггүй; backend дараа.
- Брэндийн материал (лого, өнгө) одоохондоо байхгүй — түр орлуулагч ашиглана.

## 6. Хуудсууд

| Зам | Хуудас | Тайлбар |
|-----|--------|---------|
| `/` | Нүүр | A загвар: дээд цэс, hero + хайлт, шүүлтүүр таб, картын grid |
| `/courses/:id` | Сургалтын дэлгэрэнгүй | Төрлөөс хамааран өөр харагдана (доор) |
| `/login` | Нэвтрэх | username, нууц үг |
| `/register` | Бүртгүүлэх | username, нууц үг, нууц үг давтах |
| `/checkout/:id` | Төлбөр | QPay QR (mock), "Төлбөр шалгах" товч |
| `/my-courses` | Миний сургалтууд | Худалдаж авсан онлайн сургалтууд (нэвтэрсэн байх шаардлагатай) |
| `/learn/:id` | Хичээл үзэх | Зүүн/дээд талд хичээлийн жагсаалт, видео тоглуулагч (худалдаж авсан байх шаардлагатай) |
| `/about` | Бидний тухай | Энгийн мэдээллийн хуудас |
| `/contact` | Холбоо барих | Утас, имэйл |
| `*` | 404 | |

### Нүүр хуудас (A)
- Дээд цэс: лого (түр "WAY" текст), Сургалтууд, Бидний тухай, Холбоо барих, баруун талд Нэвтрэх (нэвтэрсэн бол username + "Миний сургалтууд" + Гарах).
- Hero: гарчиг, дэд текст, хайлтын талбар — нэрээр шүүнэ.
- Таб: Бүгд / Танхим / Онлайн.
- Карт: зураг, төрлийн шошго, нэр, үнэ; танхим → эхлэх огноо + хичээлийн тоо; онлайн → видеоны тоо + нийт хугацаа.

### Сургалтын дэлгэрэнгүй
- **Танхим:** зураг, нэр, тайлбар, багш, хуваарь (эхлэх огноо, өдөр/цаг), хаяг, хичээлийн тоо, үнэ, тод "Бүртгүүлэх бол залгана уу: 88777988" блок (утсан дээр `tel:` холбоос).
- **Онлайн:** зураг, нэр, тайлбар, багш, хичээлийн жагсаалт (нэр + үргэлжлэх хугацаа; агуулга түгжээтэй харагдана), үнэ.
  - Нэвтрээгүй → "Худалдаж авах" дарахад `/login`-руу, амжилттай нэвтэрсний дараа буцаж ирнэ.
  - Нэвтэрсэн, аваагүй → `/checkout/:id`.
  - Аль хэдийн авсан → "Үзэх" товч → `/learn/:id`.

### Төлбөр (mock QPay)
- Сургалтын нэр, үнэ, QR зураг (placeholder), банкны апп-аар уншуулах заавар.
- *(Claude-ийн шийдвэр)* Утсан дээр QR-ийг өөрөө уншуулж чадахгүй тул QR-ийн доор банкны апп-уудын товчлуурын жагсаалт (QPay-ийн `urls` — нэр, лого, deeplink) харуулна. Mock `createPayment()` нь `{ invoiceId, qrImage, urls: [{ name, logo, link }] }` буцаана.
- "Төлбөр шалгах" товч → mock амжилттай → худалдан авалтыг хадгалаад `/learn/:id` руу.

## 7. Mock өгөгдөл ба backend-д бэлтгэх

- Бүх өгөгдлийн хандалтыг нэг давхаргаар (`src/api/`) дамжуулна: `getCourses()`, `getCourse(id)`, `login()`, `register()`, `createPayment()`, `checkPayment()`, `getMyCourses()` гэх мэт. Эдгээр нь `Promise` буцааж, бага зэрэг хоцрогдол дуурайна. Backend бэлэн болоход зөвхөн энэ давхаргыг солино.
- Mock сургалт: ~8 ширхэг (танхим 3–4, онлайн 4–5), Монгол нэр, ₮ үнэтэй.
- Хэрэглэгч, нэвтрэлт, худалдан авалтыг `localStorage`-д хадгална (хуудас refresh хийхэд алга болохгүй).
- Видео: нийтэд нээлттэй жишээ видео URL эсвэл placeholder.
- *(Claude-ийн шийдвэр)* Backend-ийг хэрэглэгч өөрөө дараа нь хийх тул **API-ийн гэрээг frontend тодорхойлно**. `src/api/` доторх функц бүрийн оролт/гаралтыг JSDoc-оор баримтжуулна.
- *(Claude-ийн шийдвэр)* Нэвтрэлт: `login()` нь `{ token, user }` буцаана; token-ийг хадгалж, API дуудлага бүрт `Authorization: Bearer` толгойгоор илгээх бүтэцтэй байна. Худалдаж авсан эсэхийг `getMyCourses()`-оос авсан id-ийн жагсаалтаар шалгана.

## 8. Техникийн сонголтууд (Claude-ийн шийдвэр — хэрэглэгч засаж болно)

- **Vite + React + JavaScript** (TypeScript биш — энгийн эхлэл).
- **React Router** (`BrowserRouter`) — хуудас хоорондын шилжилт. Хостинг дээр бүх замыг `index.html` руу чиглүүлэх rewrite тохиргоо хэрэгтэй.
- **Tailwind CSS** — загварчлал; өнгийг нэг газар (theme) тодорхойлж, брэнд ирэхэд солиход хялбар.
- Нэвтрэлтийн төлөвийг React Context-оор.
- UI хэл: зөвхөн Монгол (кирилл).
- Урьдчилсан нөхцөл: **Node.js суулгах шаардлагатай** (одоо компьютер дээр байхгүй).

## 9. Нээлттэй асуулт

- **SEO / Facebook урьдчилсан харагдац чухал уу?** Чухал бол Vite биш **Next.js** (эсвэл prerender) ашиглах хэрэгтэй. Хариулт ирэх хүртэл §8-ийн стек батлагдаагүй.
